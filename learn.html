Cyber Security Learning Center

What is Cyber Security?

Cyber Security is the practice of protecting computers, networks, applications and data from cyber attacks, unauthorized access and digital threats.

What is Phishing?

Phishing is a cyber attack where attackers pretend to be trusted organizations and try to steal passwords, banking details or personal information through fake emails, messages or websites.

What is Malware?

Malware is malicious software created to damage devices, steal information or gain unauthorized access to systems.

What is Ransomware?

Ransomware locks or encrypts files and then demands money from the victim in exchange for restoring access.

What is Encryption?

Encryption converts readable information into encoded data that can only be read using a correct key or password.

What is Ethical Hacking?

Ethical hacking is the practice of legally testing computer systems, networks and applications to identify security weaknesses before malicious attackers can exploit them. Ethical hackers help organizations improve their security.

What is Two-Factor Authentication (2FA)?

Two-Factor Authentication adds an extra layer of protection by requiring a second verification step such as an OTP, mobile app confirmation or security key.

What is a Firewall?

A firewall is a security system that monitors and controls incoming and outgoing network traffic according to predefined security rules.
